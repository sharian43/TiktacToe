# Tic-Tac-Toe with AI and Machine Learning
This project is a Python-based Tic-Tac-Toe game where a human player competes against an AI. The AI is powered by a machine learning model trained to predict optimal moves based on game states.
# Features
Interactive Game: Play against the AI in a command-line interface.
AI Opponent: The AI uses a neural network trained to predict the best move based on the current board state.
Dynamic Gameplay: Handles player moves, AI responses, win/loss detection, and draws.
Machine Learning Integration: The AI is trained on simulated games to learn winning strategies.

# Install the dependencies using:
pip install numpy tensorflow ipython

# How to Run
1. Clone the repository:
git clone https://github.com/your-username/tic-tac-toe-ai.git
cd tic-tac-toe-ai
2. Open the Jupyter Notebook:
jupyter notebook
3. Or run the script directly:
python tic_tac_toe.py
4. Follow the on-screen prompts to play the game.
